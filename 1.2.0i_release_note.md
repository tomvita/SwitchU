# SwitchU fork 1.2.0i

Breeze can now be your HOME screen. With one flag file, the console boots into
Breeze instead of the SwitchU menu, and HOME from a game brings Breeze back.
The SwitchU menu stays one button away in Breeze. Without the flag, nothing
changes.

Deploy the daemon and the menu together — `atmosphere/contents/…/exefs.nsp`
and `switch/SwitchU/bin/menu/main` are built as a pair. Nothing the two share
changed in this release, so a 1.2.0b–1.2.0h menu also works with this daemon.

The Breeze interface level goes from 3 to 4, so a Breeze can tell that the
installed fork supports Breeze first. Breezes that don't know about it keep
working as before.

## Breeze first

Create an empty file `sdmc:/config/SwitchU/breeze_first` and reboot. From then
on the daemon opens Breeze wherever it used to open the SwitchU menu:

- at boot;
- on HOME from a game, when Breeze isn't already open behind it;
- when a game exits, and when a launch fails.

The Breeze Home toggle works as before: HOME switches between Breeze and the
game, in the mode you picked in Breeze. Games started from Breeze replace the
running one, as in 1.2.0h.

When Breeze closes with no game running, it opens again. When it closes with a
game suspended, the game resumes. HOME inside Breeze with no game does nothing,
since Breeze is already HOME. If Breeze closes three times in a row within
seconds of opening, the SwitchU menu takes over until the next reboot, so a
broken Breeze can't leave the console unusable.

Breeze's **SwitchU** button still opens the SwitchU menu. From there you can
use the menu as usual. The next HOME from a game goes back to Breeze.

Delete the file and reboot to return to the SwitchU menu.

## Where Breeze runs

If Breeze's profile shortcut is installed
(`atmosphere/contents/0100000000001013/exefs.nsp`), Breeze opens through the
User Page, as when you open your profile.

Without it, Breeze borrows the Album for as long as it is open, the same way
the SwitchU menu does. The loader for this ships with the fork in
`atmosphere/contents/0100000000001000/breeze_loader/`, next to the daemon.
Nothing on the SD card is swapped, and the Album is the normal Album (hbmenu)
whenever Breeze isn't using it.

## Without the SwitchU menu

The daemon, its Breeze loader and Breeze are enough for a working console. If
`switch/SwitchU/bin/menu` is missing, Breeze is HOME even without the flag.

If neither the menu nor Breeze can start, the daemon opens the plain Album, so
hbmenu comes up instead of a black screen. HOME from a game opens it on the
first press, and HOME in it returns to the game.
