# SwitchU fork 1.2.0h

Homebrew can start games again. hbmenu and sphaira in the Album, Breeze, and
forwarders can all launch an installed title, and SwitchU switches to it the way
it does for a launch from its own menu.

Deploy the daemon and the menu together — `atmosphere/contents/…/exefs.nsp`
and `switch/SwitchU/bin/menu/main` are built as a pair. Nothing the two share
changed in this release, so a 1.2.0b–1.2.0g menu also works with this daemon.

The Breeze interface level stays at 3. Breeze needs nothing new: its game
launches simply work now.

## Launching a game from homebrew

A homebrew app starts a game by asking the system to launch it; the system then
hands that request to the HOME menu, which is SwitchU's daemon. The daemon
ignored those requests, so a launch from hbmenu, sphaira or Breeze did nothing.

The daemon now takes the request and:

- closes whatever is in front — the Album or User Page applet running the
  homebrew, a Breeze held behind the game, or the SwitchU menu — without
  reopening the menu afterwards;
- closes the game that is running, if any. When a forwarder or other homebrew
  running as a game asked for the launch, that is the one closed. A title that
  doesn't exit within 15 seconds is terminated;
- starts the requested title with its save data prepared, and with a user
  already selected when the title takes one: the user of your last launch from
  the SwitchU menu, otherwise the user the system picks without asking (for
  example the only one), otherwise the first user.

HOME, resume and the Breeze toggle then work with the new game as usual.

Forwarders keep working as before when you start them from the SwitchU menu.
They can now launch games themselves, and homebrew can launch a forwarder.

## Old logs are kept in the right order

SwitchU keeps the last four logs of each kind in `config/SwitchU/`. The daemon
starts before the console clock is set, so its old logs are all named
`daemon-1970-01-01_…`, and the cleanup deleted by name. That often removed the
newest log instead of the oldest, so the log of the session you wanted to report
was gone after a reboot. Old logs are now removed by the date the SD card
recorded for them.
