# SwitchU fork 1.2.0k

Games started from sphaira, forwarders or Breeze now work the first time,
even if the SwitchU menu hasn't shown them yet.

Deploy the daemon and the menu together — `atmosphere/contents/…/exefs.nsp`
and `switch/SwitchU/bin/menu/main` are built as a pair. Only the daemon
changed in this release, so a 1.2.0b–1.2.0j menu also works with this daemon.

## First launch from other programs

The daemon reads a game's startup settings from the cache the menu fills when
it lists the game. A game installed while the menu wasn't listing titles,
from DBI for example, had no entry yet. Started from sphaira, a forwarder or
Breeze, it then got no save data and no user, so it quit right after its
logo. Starting it once from the menu fixed it.

The daemon now reads a missing game's settings from the system directly, and
caches them for next time.

## Atmosphere 1.12.0 libraries

The daemon is built against the Atmosphere 1.12.0 libraries (Horizon 23.0.0)
and the current libnx.
